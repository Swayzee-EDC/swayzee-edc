# Dependencies
- npm
- hugo

# Install
```shell
# get the source
git clone --recursive git@github.com:csparker247/swayzee-edc.git

# install requirements
npm install
```

# Build
```shell
npm run build
```

# Run the dev server
```shell
# start the web server
hugo server --port 3000

# in a new terminal, start the visual editor
stackbit dev
```
